The project

Input with a visible consequence.

My work on this Unreal Engine project focused on player input actions and character animation. The Blueprint movement logic connects specific inputs to changes in character behavior, including float and slam actions that adjust gravity.

The project brings together character control, movement logic, and equipment attachment in a blockout environment.

My contributions

  • Worked on player input actions and character animation.
  • Built Blueprint logic for input-driven changes to character movement.
  • Set up float and slam actions with different gravity behavior.
  • Worked on socket-based attachment of equipment to a character.
Scope of this case study

The work presented here focuses on gameplay implementation and character setup. Character and environment assets are used to demonstrate those systems.

Blueprint implementation

Two inputs. Different movement states.

  1. Float

    The float input reduces the character’s gravity scale while the action is active. When the action completes, the graph restores the normal gravity setting.

  2. Slam

    The slam input stops the character’s current movement and increases gravity. When the action completes, the graph restores the normal gravity setting.

These examples show how input actions can drive temporary changes to character movement through Blueprint logic.

Animation & attachments

Alongside input and movement, I worked on character animation and socket-based equipment setup. Sockets provide an attachment point on the character, while the input logic controls how the character responds to player actions.

Together, these pieces form the technical foundation of the character-control work in this project.
